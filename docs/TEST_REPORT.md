## 发现并修复

1. XLSX 缺少行数元数据时预览异常：允许未知预估，导入时精确计数。
2. 队列领取混合状态排序导致大表反复扫描：拆分状态索引查询。
3. 每次小操作重建连接/检查点开销：按线程复用 WAL 连接，线程完成关闭。
4. 高配额模拟时限流历史反复求和：改为双端队列与滚动 Token 合计。
5. 重用连接遗留临时 ID 表：每次显式清空后重填，A/B 创建可重复执行。
6. 供应商无效 JSON 已经计费但本地丢用量：先提取 usage，失败也记录；缺失用量暂停核对。
7. 启动器默认控制台子系统：强制 GUI 子系统，并通过 PE 结构断言检查。
8. 导入元数据重复携带正文导致真实长文无法分段：按原始人工映射仅排除正文列，数据库保留全原值；自定义正文列与同名辅助字段分别测试。

最后修正后的源码另运行 1,000 篇全链路模拟，见 [PERFORMANCE_FINAL_SMOKE.json](PERFORMANCE_FINAL_SMOKE.json)，全部成功。20 万压力记录验证主要队列大规模路径；后续元数据传输修正、HTML 与案例使用计数通过最终回归和该补充模拟验证。
