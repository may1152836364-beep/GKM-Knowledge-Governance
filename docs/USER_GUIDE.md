# GKM 使用说明（候选版 0.1.0）

## 启动
Windows 10（建议 22H2）/11 x64、建议 8 GB 以上内存及 20 GB 可用磁盘。将整个 Windows 压缩包解压到有读取权限的目录，双击 **GKM.exe**。不要只拷贝 EXE，不必安装 Python，不需要 CMD，不占用本地 TCP 端口。本候选包尚待真实 Windows 启动验收，未代码签名，公司安全策略可能要求管理员审核。

数据默认位于 `%LOCALAPPDATA%\GKM`，与程序目录分离。升级时不要覆盖或删除此目录。只允许一个窗口使用同一数据目录。

## 导入
进入“文章数据”，选择一个或多个 XLSX，或把文件拖进窗口。选择工作表，核对前 20 行和字段映射。ID、标题、正文、语言必须映射；缺 ID/语言及公式行隔离并记入报告，缺标题/正文允许入库但不可正常分析。数值 ID 的 Excel 全零数字格式可保留前导零；如果原文件已损失前导零，无法凭空恢复。

同一业务来源的文件使用相同“来源范围”；不同独立知识库使用不同来源范围以免合并同 ID。重复当前版本不新增，正文或元数据变化保留历史版本。原文不覆盖，默认清洗仅统一换行。可在“清洗策略 / 撤销”中选择可读 HTML 策略，保留段落、表格分隔、链接及图片说明，不执行脚本或加载图片；转换后请审阅差异，随时切回原文策略。正文达到 32,767 字符时报告截断风险，应回源系统核查。

导入报告可保存 JSON；列表分页、标题/ID 搜索、语言与发布状态过滤。原文/清洗/历史版本均可查看。未知 Excel 列原名原值保留。

## 配置模型
在“模型与系统设置”新增模型：名称、企业批准的 HTTPS base_url（通常含 `/v1`，也可填完整 `/chat/completions`）、模型 ID、API Key。输入密钥为密码框，不会回显已有密钥。编辑时密钥留空保留。

填写供应商文档规定的上下文字符预算、输出 Token、超时，以及同一币种的每百万 Token 输入/输出价格。价格为 0 也需明确确认。字符预算是保守运行参数，不等于供应商标称 Token 窗口。模型须支持 JSON 输出和 usage Token 统计。

点击“真实在线连接测试”：实际发送一次不含文章的 JSON 小请求，可能产生微量费用。更换地址、模型、密钥或参数后需重测。401/403 检查鉴权和授权；404 检查 endpoint/模型；429 降低速率；超时检查网络；证书失败应修复信任链，不允许关闭 TLS 校验。

密钥通过 Windows 当前用户 DPAPI 加密保存，不写明文数据库。换电脑/Windows 用户时需重新配置。Linux 开发版不提供明文回退。

## 全量任务
进入“AI 智能识别”，选择通过测试的模型，查看规模及粗略费用，创建任务。默认所有可分析文章都登记任务，不因已下架、英文或低风险跳过。可选导入批次、未分析的新版本或手工 ID。配置总预算、单次调用费用上限、并发、RPM、TPM、重试次数，并逐任务确认公司数据外发授权。

任务创建时冻结文章版本、模型密钥引用、提示词/规则、审核案例及基准日期。点击“开始 / 继续”才派发。只发送所选供应商的分析必需数据，无遥测，无外部事实搜索。

暂停经过“运行中 → 暂停中 → 已暂停”：暂停中不会派发新调用，在途请求受配置超时限制。成功结果保留，进度稳定后可退出；重新打开后继续剩余任务。致命鉴权错误或预算不足自动暂停。预算使用下一请求的保守上限预留，可能提前于预算耗尽暂停。接口 usage 为实际费用统计依据，最终账单以供应商为准。

取消需要确认，会保留成功结果并取消未开始项。失败页显示 HTTP 状态、可读原因与修复建议；修正密钥并测试通过后，可用任务页“更新任务密钥”显式更换凭据而保留业务快照；“仅重试失败”后点继续。调用日志显示用量、分段/汇总类型，不含正文和密钥。无法在通用接口保证崩溃边界的供应商零重复计费；恢复提示需核查未提交的在途请求。

## 证据复核与案例
结果页可筛选建议及复核状态，双击结果查看原文与分析，选择有效证据并定位高亮。无效引文隔离标记，不能作为真证据。影响范围、有效性与建议独立；下架评估必须满足额外保护门槛；软件没有自动上下架接口。

复核须填写结论、理由和复核人，AI 原结论不变。可同时生成待审核案例；案例经人工审核后仍保持停用，需包含当前案例版本、同一固定集的前后对照回归报告达标并由人员批准后启用，才供新任务检索。案例修改后重新待审核；停用/归档不会改旧任务快照。支持手动编辑及 JSON 数组导入，字段见 `docs/CASE_TEMPLATE.json`。召回为中英文文本匹配，并非语义向量训练。

提示词/规则保存为新草稿版本，旧版本可复制回滚。版本发布须固定至少 500 篇金标准集前后回归、达到批准阈值且不低于基线，无缺失/无效证据，并人工批准。可先选择草稿提示词或候选案例创建“回归验证”任务，再在规则页对同一金标准集评估基线和候选任务，生成版本绑定报告；回归结果不使生产“新增/修改”范围误跳过。不要伪造回归报告；无真实标注集时只能做开发验证。

## 导出与维护
Excel 导出含原始 ID、语言、发布状态、建议、证据、复核、批次及版本，并对公式注入做转义。请将导出文件存放在公司授权目录。

设置页可备份 SQLite、恢复并自动保留恢复前备份、导出脱敏操作日志和查看环境诊断。恢复前必须暂停所有任务。备份含知识正文和复核，视为敏感文件；数据库备份不包含 `keys` 目录密文，跨用户恢复后重新录入密钥。
