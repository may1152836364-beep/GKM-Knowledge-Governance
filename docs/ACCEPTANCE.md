## 必须说明的边界

- 通用 Chat Completions 无事务/幂等接口：供应商已响应而本地尚未提交时崩溃，无法承诺供应商零重复计费。恢复时提示核查；本地已成功提交项不重复派发。
- SQLite WAL NORMAL 在进程崩溃下可恢复；突然断电/操作系统故障可能丢失最近事务。重要数据定期备份，不宣称电源故障下零丢失。
- 窗口预算用保守字符设置，Token 以供应商 usage 为准；汇总无法容纳全部分段结果时明确失败，绝不静默截尾。未采用递归超大汇总或厂商批量 API。
- 当前首页以统计卡片/维度表呈现；尚无可交互图表、联网自动更新和跨语言向量检索（后两者分别属于系统后续完善和 P1）。生产密钥不在 Linux 保存。
- 候选 EXE 未代码签名，PE/依赖静态检查不能替代 Windows 双击运行、安全软件兼容性、实际网络代理联调。
